# צלחת

יומן תזונה אישי בעברית: רושמים מה אוכלים ומקבלים ניתוח יומי, שבועי וחודשי מול יעד קלורי ויעד חלבון.

**לאפליקציה:** https://sallaryandpension.github.io/tzalachat/

- כ-320 מאכלים ישראליים נפוצים עם מנה טיפוסית, ועוד כ-4,500 מאכלים ממאגר התזונה הלאומי "צמרת" של משרד הבריאות (data.gov.il), כולל יחידות ביתיות.
- יעד קלורי לפי נוסחת Mifflin-St Jeor, ויעד חלבון לפי רמת הפעילות והמטרה.
- כמה משתמשים, ולכל אחד פרופיל ויומן משלו.
- הנתונים נשמרים בדפדפן של המשתמש בלבד (localStorage). הם לא נשלחים לשום שרת, ולא עוברים בין מכשירים.

הקבצים:
- `index.html` — האפליקציה.
- `foods.json` — המאכלים הנפוצים.
- `tzameret.json` — כל המאכלים ממאגר צמרת, ל-100 גרם, עם יחידות ביתיות.

המידע התזונתי הוא למידע כללי ולא מחליף ייעוץ של דיאטנית או רופא.
